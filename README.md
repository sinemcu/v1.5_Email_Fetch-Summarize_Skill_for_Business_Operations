# v1.5_Email_Fetch-Summarize_Skill_for_Business_Operations
The skill chain for agents in order to get attachments from email by day and summarize using the specific template.
To use this:
1. Enter the password and account into email-fetch/password.json ;
2. Say please use email-fetch to get the data on ...(the date, today or yesterday are also okay) and use summarise to output it ;
3. The default email box is sino owa, the default output dir is ./Downloads, if you want to change please tell the agent in advance.
